# EcoMove -- Smart Waste Pickup & Transportation System

**Organize. Book. Recycle.**

EcoMove is a student project prototype designed to improve waste
segregation, pickup booking, and waste transportation.

## Problem

Poor waste segregation can cause contamination, unsafe handling, and
inefficient waste collection.

## Features

-   ♻️ Waste segregation guide
-   📅 Waste pickup booking
-   📍 Pickup tracking using Booking ID
-   📋 My Bookings
-   🛠️ Admin Dashboard
-   🚛 Transportation management

## Waste Categories

-   Wet Waste
-   Plastic
-   Paper & Cardboard
-   Glass
-   Metal
-   E-Waste

not include a real backend, live GPS tracking, online payments, or
municipal integration.
